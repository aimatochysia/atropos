## What's new in 0.7.2

**One kind of vault, in two sizes.** What used to be a "package" is now simply a **Vault**: one encrypted `.atropos` file that is easy to copy, upload or send. What used to be a vault folder is now a **Vault LFS**: a folder that encrypts each file on its own, so very large collections stay fast. Both are on the Home list and work the same way.

- **Same unlock options everywhere**: a single-file Vault now has a password, a 24-word recovery phrase, fingerprint unlock and security cards, just like a Vault LFS. Re-key, check and repair work too.
- **Pick the kind when creating**: "New vault" asks for Vault (one file) or Vault LFS (a folder). You can make a copy as the other kind later from the vault menu ("Make a Vault LFS copy" / "Make a single-file copy"). The copy keeps the same password and recovery phrase, and the original stays where it is.
- **Older .atropos files**: files made before 0.7.2 show under "Older .atropos files" on Home. Tap one to upgrade it in place: its passphrase becomes the vault password and you get a recovery phrase. "Just look inside" opens it as before without changing it. Files sealed to another vault still open from that vault's menu.
- **"Open an existing vault"** on Home takes either a vault file or a Vault LFS folder.

**Managing files inside a vault**

- **New text file** and **New Markdown note** in the Add menu; the editor opens straight away.
- **Cut, Copy and Paste**: pick items up with Cut or Copy (from an item's menu or the selection bar), open any folder, then tap **Move here** or **Paste here**.
- **Drag and drop**: drag files onto a folder, or onto a folder name in the path bar above the list, to move them. On phones, long-press, then drag; letting go without moving opens the item's menu as before. Dragging a selected item moves everything selected.
- **Make a copy** of a file or a whole folder. Copies share their encrypted data, so they are instant and take no extra space.
- **Folder menu**: Open, Add files here, New folder inside, and Details with how many files and folders it holds and their total size.
- **New folder** right inside the "Move to…" dialog.
- **Drop files from Explorer, Finder or your file manager** onto an open vault (Windows, macOS, Linux) to encrypt them into the folder you are in.

**Fixed**

- "Save as copy" after editing a picture in a Vault LFS saved an empty file. It now saves the edited picture.
