## What's new in 0.7.0

Atropos now works like a normal file app inside your vaults and packages: sort, search, open files the way you want, find inside them and make quick edits, all without anything leaving the encrypted vault.

### Finding your way around
- **Sort** any vault or package by name, date modified (the file's own date, not when it was added), type or size, ascending or descending. Folders stay on top. Each vault remembers its own order.
- **Search a vault by name**: the magnifier in a vault finds files and folders anywhere inside it and takes you there.
- **Next and previous file**: in the viewer, swipe sideways, use the arrow keys or the arrows in the top bar to move through the folder.
- **Recent packages** are listed on the home screen by file name, so you can reopen one in a tap (it still asks for its passphrase or vault). Remove any of them with ×, or turn the list off in Settings, which also clears it.

### Opening files
- **Open as**: long-press or right-click a file (or use ⋮) to read it as text, Markdown, a picture, a PDF or audio. In a vault the choice is kept with that file inside the encrypted file list. In packages it is kept for that file type on this device.
- The same menu has **Details**, **Export or Extract this one file** (with a warning that it is written unencrypted), and in a vault Rename, Move, Delete and Select.

### Reading
- **PDFs zoom in place**: pinch, double-tap, Ctrl + scroll wheel or the + and − buttons. No more second tap to open a single page. A page counter shows where you are.
- **Find** in text, Markdown and PDF files: matches are highlighted (pages in PDFs), with next and previous and a match-case switch. Ctrl+F opens it.
- **Pictures**: turn the view, and see photo details (camera, lens, exposure, date taken and location, when the photo has them).

### Editing
- **Text in packages can be edited now**, like in vaults. Saving writes a new copy of the package next to it and swaps it in, so a crash leaves either the old or the new package, never a broken one.
- **Picture editing**: rotate, flip, crop and resize, then Save (replace) or, in a vault, Save as a copy. The picture is re-encoded in its own format, which removes camera details and location from the saved file.
- On Android, a package picked from internal storage or an SD card is opened where it is, so edits are saved into that file. Packages from cloud or app storage open as a temporary read-only copy.

### Updates
- **Look for updates** in Settings: never, every start, once a day or once a week.
- When a new version is found, its release notes pop up once with **Update**, **Later** and **Skip this version**. After that the banner on the home screen stays until you update or skip.
